Приложение «Мероприятия» (Android)

Файл установки:
- events-mobile-1.0.0-arm64-v8a.apk — для большинства современных смартфонов (64-бит ARM).

Требования: Android 7.0 и выше (в т.ч. Android 11).

Установка:
1. Скачайте APK на смартфон.
2. Разрешите установку из неизвестных источников (Настройки → Приложения → Специальный доступ).
3. Откройте скачанный файл и подтвердите установку.

Приложение работает с сервером https://events.elprof.ru.
